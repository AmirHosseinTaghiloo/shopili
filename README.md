# 🛍️ Shopily

### Modern E-Commerce Platform Built with Nuxt 3

**Shopily** is a modern, responsive e-commerce web application built with **Nuxt 3** and **Vue.js**, focused on delivering a smooth, fast, and intuitive online shopping experience.

The project is designed with a scalable component-based architecture and modern frontend development practices.

---

## ✨ Features

* 🛍️ Modern e-commerce interface
* 🔍 Product search
* 🗂️ Product categories
* 🛒 Shopping cart
* ❤️ Wishlist
* 📦 Product details
* 💰 Product pricing & discounts
* 📱 Fully responsive design
* ⚡ Fast and optimized user experience
* 🧩 Reusable components
* 🔄 Dynamic product data
* 🧭 Client-side navigation with Nuxt Router

## 🧱 Architecture

Shopily follows a component-based architecture powered by Nuxt 3.

```text
shopily/
│
├── assets/
│
├── components/
│   ├── ProductCard.vue
│   ├── Navbar.vue
│   ├── Footer.vue
│   └── ...
│
├── pages/
│   ├── index.vue
│   ├── products/
│   ├── cart.vue
│   └── ...
│
├── layouts/
│
├── composables/
│
├── stores/
│
├── public/
│
├── app.vue
├── nuxt.config.ts
├── package.json
└── README.md
```

> The project structure may evolve as the application grows.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/AmirHosseinTaghiloo/shopily.git
```

### 2. Navigate to the project

```bash
cd shopily
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:3000
```

---

## 📦 Production

Build the application:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
